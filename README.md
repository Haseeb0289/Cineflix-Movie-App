# Cineflix – Movie Streaming App

Cineflix is a **React Native** mobile application that allows users to browse, search, and stream movie details seamlessly. It provides a modern UI and integrates with a **GraphQL backend API** for real-time data fetching.

---

- ✅ **Browse Movies:** View trending, popular, and upcoming movies.
- ✅ **Search Functionality:** Find your favorite movies easily.
- ✅ **Detailed Movie Info:** Get cast, rating, and description for     each movie.
- ✅ **GraphQL Integration:** Fast and efficient API queries.
- ✅ **Responsive UI:** Built for both **Android** and **iOS**.



## Tech Stack
**Frontend:**
- React Native EXPO
- React Navigation

**Backend:**
- Node.js
- Express.js
- GraphQL
